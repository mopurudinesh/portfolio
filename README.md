# 🛠️ Tech Stack & Development Tools

I carefully selected technologies that provide scalability, maintainability, and modern development efficiency.

---

## ⚛️ Frontend & Core Architecture

### 🔹 React 18

The foundational UI library powering the entire component-based architecture.

### 🔹 TypeScript

Implemented strict static typing to improve:

* Code reliability
* Maintainability
* Scalability
* Developer productivity

### 🔹 Vite

Chosen for:

* ⚡ Lightning-fast Hot Module Replacement (HMR)
* 🚀 Optimized production builds
* 🧩 Modern development workflow

---

## 🎨 Styling & UI Components

### 🔹 Tailwind CSS

Used for rapid and highly customizable UI development through a utility-first approach.

### 🔹 shadcn/ui + Radix UI

Integrated accessible component primitives and customized them extensively to match the project’s visual identity.

### 🔹 Framer Motion

Used to create:

* Smooth animations
* Layout transitions
* Motion effects
* Interactive experiences

---

# 📦 State Management & Form Handling

### 🔹 React Hook Form + Zod

Built a highly optimized and type-safe form validation system for the contact section.

### 🔹 EmailJS

Integrated EmailJS to enable direct client-side communication without requiring a dedicated backend server.

This approach simplified deployment while maintaining functionality and responsiveness.

# 📂 Repository Structure

To maintain clean architecture and scalability, I organized the project into modular and reusable components.

```text
portfolio/
├── public/                    # Static assets including resume and images
├── src/
│   ├── components/            # Reusable React components
│   │   ├── About.tsx          # Personal introduction section
│   │   ├── Certifications.tsx # Professional certifications showcase
│   │   ├── Contact.tsx        # EmailJS-powered contact form
│   │   ├── Experience.tsx     # Work experience timeline
│   │   ├── Projects.tsx       # Interactive project showcase section
│   │   ├── Skills.tsx         # Technical skills and technologies
│   │   └── ui/                # Shared UI components
│   ├── App.tsx                # Main application wrapper
│   └── index.css              # Global styles and theme configuration
└── tailwind.config.ts         # Tailwind custom themes & animations
```
